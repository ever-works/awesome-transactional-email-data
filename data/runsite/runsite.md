## Overview

Runsite is a European Platform-as-a-Service (PaaS) based in Germany that provides automated deployments from GitHub for web services and static sites, managed databases, S3-compatible object storage, and transactional email sending. It positions itself as an all-in-one cloud platform for starting and running websites and web services.

## Key Features

- Automated deployments from GitHub for web services or static sites
- One free web service with 0.1 vCPU and 256 MB RAM
- Managed PostgreSQL and Valkey (Redis), free for 30 days
- Transactional email: 3,000 emails per month free
- S3-compatible storage: 5 GB free
- Servers located in Germany

## Pricing Model

Freemium — a free tier is available with the allowances listed above; additional resources and capacity are offered on paid plans.

## Deployment

Cloud — hosted in Germany (EU).
