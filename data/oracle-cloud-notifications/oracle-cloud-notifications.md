## Overview

Oracle Cloud Notifications is a cloud-native pub/sub messaging service that supports email delivery among other notification channels. It is part of Oracle Cloud Infrastructure's always-free tier.

## Features

- Email delivery as part of notifications service
- 1 million delivery options per month (free tier)
- 1,000 emails sent per month (free tier)
- Part of Oracle Cloud Infrastructure

## Pricing

Free tier includes 1,000 emails per month. Part of Oracle Cloud's always-free offerings.

## Deployment

Cloud (Oracle Cloud Infrastructure)
