## Overview

Mox is a modern, open-source mail server designed for simplicity and security.

## License

Released under the MIT license.

## Features

- IMAP protocol support
- SMTP protocol support
- Submission service
- Written in Rust
- Minimal configuration required
- Modern security practices

## Repository

Source code available at https://github.com/mox.
