## Overview

Stalwart is an open-source mail server written in Rust that supports IMAP, JMAP, SMTP, and submission protocols.

## License

Open-source software.

## Features

- IMAP protocol support
- JMAP protocol support
- SMTP protocol support
- Submission service
- High performance
- Low resource usage
- Automatic banning
- Authentication support
- Storage options

## Editions

Community edition and Enterprise edition available.

## Repository

Source code available on GitHub.

## Pricing

Community edition is free and open-source. Enterprise edition is a paid commercial product.
