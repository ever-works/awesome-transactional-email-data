## Overview

Zimbra is a commercial email and collaboration platform that provides email, calendaring, contacts, and document sharing capabilities.

## License

Available in open-source and network editions. Open-source edition released under MPL, AGPL, and Yahoo Public License.

## Features

- Email, calendaring, and contacts
- Document sharing and briefcase
- Web-based client interface
- IMAP, POP3, and SMTP protocol support
- Mobile device synchronization
- Anti-spam and anti-virus integration

## Editions

- Open Source Edition: free, community-supported
- Network Edition: paid, enterprise features and support

## Repository

Source code available on GitHub.

## Pricing

Open Source Edition: free. Network Edition: paid commercial licensing.
