## Overview

Dovecot is an open-source IMAP and POP3 server for Unix-like operating systems, written primarily with security in mind.

## License

Released under the GNU General Public License version 2 (GPLv2).

## Features

- IMAP and POP3 protocols
- Multiple mailbox formats (Maildir, mbox, dbox, mdbox)
- Authentication via PAM, passwd, SQL, LDAP, and other backends
- TLS/SSL support for encrypted connections
- Mail storage indexing for performance
- Virtual mailbox support
- Quota support
- Full-text search via Solr and Lucene
