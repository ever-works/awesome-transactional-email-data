## Overview

turboSMTP is an SMTP relay service.

## Key Features

- Free: 200 emails per day or 6,000 emails per month
- Free forever, no time limit or expiry
- Web API
- SPF/DKIM authentication
- Suppression management
- 1 sending domain, 2 API keys
- 2FA, ticket and chat support
- GDPR compliant

## Pricing

Free tier (200 emails/day or 6,000/month). Paid plans for higher volumes.
