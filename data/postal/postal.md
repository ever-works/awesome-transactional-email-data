## Overview

Postal is an open-source, self-hosted mail delivery platform for websites and web servers. Positioned as an alternative to commercial services like SendGrid, Mailgun, or Postmark, it enables organizations to run their own mail infrastructure.

## Key Features

- **Comprehensive Web Interface**: Manage mail servers and view mail logs through an easy-to-use web interface.
- **Scalable**: Horizontally scale your mail service up and down as needed.
- **Webhooks**: Set up webhooks to notify HTTP endpoints when messages are delivered or encounter issues.
- **Development Mode**: Automatically hold messages in Postal as needed to handle testing during development.
- **IP Pools**: Send mail from different IP addresses to help build and maintain good IP reputation.
- **Spam & Anti-Virus Integrations**: Integrate with SpamAssassin, rspamd, and ClamAV to have incoming and outgoing messages checked for threats and spam.

## Deployment

Self-hosted; deploy on your own servers.
